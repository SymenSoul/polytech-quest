# Polytech Cyber Quest

Квест «Исчезновение цифрового гения» для школьников: 5 этапов (SQL, Python, безопасность, сети, Git).
Команды регистрируются, проходят этапы, а сервер считает время, ошибки и подсказки и ведёт таблицу результатов.

Логин вводить не нужно: сервер выдаёт команде уникальный позывной вида «Хитрый Барсук» или «Мудрая Сова»
(его можно сменить кнопкой «Другой вариант» до старта). Словарь — в `server/nicknames.js`; он подобран так,
чтобы ни одно сочетание не было обидным. Участников и класс можно указать по желанию.

## Запуск на сервере для занятия

Нужен Node.js 20.19 или новее (https://nodejs.org).

```bash
npm install
npm run build
npm start
```

После запуска в консоли будут:

- адреса вида `http://192.168.1.10:8080` — их ученики открывают в браузере на своих компьютерах;
- адрес таблицы результатов `/results` — удобно вывести на проектор;
- **ключ организатора** — нужен на странице `/results`, чтобы удалять строки и очищать таблицу.

Если ученики не могут подключиться, разрешите входящие подключения к Node.js в брандмауэре
(Windows обычно сам спрашивает об этом при первом запуске) и проверьте, что компьютеры в одной сети.

### Настройки (переменные окружения)

| Переменная        | По умолчанию        | Что задаёт                                   |
| ----------------- | ------------------- | -------------------------------------------- |
| `PORT`            | `8080`              | порт сервера                                 |
| `HOST`            | `0.0.0.0`           | на каком интерфейсе слушать                  |
| `ADMIN_KEY`       | случайный при старте | ключ организатора                            |
| `DATA_FILE`       | `data/results.json` | файл, где хранятся результаты                |
| `SCORE_BASE`      | `1000`              | стартовый запас баллов                       |
| `PENALTY_MINUTE`  | `10`                | штраф за каждую минуту прохождения           |
| `PENALTY_MISTAKE` | `20`                | штраф за неверный ответ                      |
| `PENALTY_HINT`    | `30`                | штраф за открытую подсказку                  |

Пример: `PORT=3000 ADMIN_KEY=olymp2026 npm start`
(в Windows PowerShell: `$env:PORT=3000; $env:ADMIN_KEY="olymp2026"; npm start`).

## Подсчёт результатов

```
баллы = старт − штраф_за_минуту × минуты − штраф_за_ошибку × ошибки − штраф_за_подсказку × подсказки
```

Баллы не уходят ниже нуля. При равенстве баллов выше команда с меньшим временем.

- **Время** считает сервер: от регистрации команды до решения последнего этапа. Перезагрузка страницы
  таймер не сбрасывает — прогресс команды восстанавливается.
- **Ошибка** — отправка неверного ответа кнопкой проверки этапа. Повторная отправка того же неверного
  варианта не штрафуется (защита от двойного клика).
- **Подсказка** — каждая открытая подсказка; повторно открывать уже показанные не нужно, они сохраняются.

Результаты хранятся в `data/results.json` и переживают перезапуск сервера. На странице `/results`
кнопка «Скачать CSV» выгружает таблицу для Excel, включая разбивку ошибок и подсказок по этапам.

## Разработка

```bash
npm run dev
```

Запускает тот же сервер с Vite и горячей перезагрузкой на порту 5173.

Структура:

- `src/` — интерфейс на React (`App.jsx` — этапы квеста, `Registration.jsx`, `Results.jsx`);
- `server/` — HTTP-сервер без внешних зависимостей: API, раздача сборки, хранение результатов;
- `shared/quest.js` — общие для клиента и сервера список этапов и формула подсчёта.
